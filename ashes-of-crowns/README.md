# ASHES OF CROWNS

یک Action RPG دوبعدی فانتزی تاریک برای مرورگر موبایل و دسکتاپ. این نسخه، شش ماژول مستقل پروژه را زیر یک Runtime مشترک به هم متصل می‌کند.

## اجرای پروژه

نیازمندی‌ها: Node.js 20 یا جدیدتر و npm.

```bash
npm install
npm run dev
```

ساخت نسخهٔ انتشار:

```bash
npm run build
```

خروجی قابل انتشار در `dist/` قرار می‌گیرد. برای Cloudflare Pages:

- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

## کنترل‌ها

| عمل | کیبورد | موبایل |
|---|---|---|
| حرکت | A / D یا جهت‌ها | جوی‌استیک لمسی |
| پرش / پرش دوم | Space | دکمهٔ پرش |
| ضربه | Z یا J | Attack |
| ضربهٔ سنگین | X | Heavy |
| جاخالی | C | Dodge |
| دفاع | V | Guard |
| تعامل | E | Interact |
| مهارت‌ها | 1 / 2 / 3 | Skill 1–3 |
| توقف | Esc | منوی بازی |
| موجودی / مهارت / نقشه / مأموریت | I / K / M / Q | منوی رابط کاربری |

دکمه‌های SHOP و CRAFT در رابط لمسی برای فروشگاه و ساخت‌وساز در دسترس‌اند. در روستای آغازین، نزدیک میدان و آهنگری می‌توان فروشگاه مربوط را با E باز کرد.

## ساختار

- `src/modules/player/` — کنترل، وضعیت و انیمیشن آرن
- `src/modules/combat/` — دشمن‌ها، باس‌ها، ضربه، وضعیت‌ها و هوش مصنوعی
- `src/modules/world/` — شش منطقه، مراحل، مأموریت‌ها، دیالوگ و پایان‌ها
- `src/modules/rpg/` — سطح، مهارت، تجهیزات، اقتصاد، ساخت‌وساز و لوت
- `src/modules/ui/` — رابط کاربری، HUD، منوها، کنترل لمسی و RTL
- `src/modules/persistence/` — ذخیره، بارگذاری، checkpoint، تنظیمات و صدا
- `src/game/` — اتصال شش ماژول، ورودی مشترک، صحنه و آداپتورهای UI

ماژول Combat در این بسته در پوشهٔ استاندارد `src/modules/combat/` قرار گرفته؛ پوشهٔ اضافی ZIP اولیه هنگام ادغام حذف شده است.

## ذخیره‌سازی

پس از هر پایان داستان، گزینهٔ New Game+ در صفحهٔ پایان ارائه می‌شود؛ سطح و تجهیزات/مهارت‌های قابل‌حفظ باقی می‌مانند و World از نو آغاز می‌شود.

ذخیرهٔ اصلی با IndexedDB انجام می‌شود و در صورت نبود آن، ماژول Persistence به حافظهٔ موقت تنزل می‌کند. وضعیت کامل RPG و World به شکل JSON در فیلدهای توسعه‌پذیر Save نگهداری می‌شود؛ وضعیت checkpoint نیز توسط خود Persistence مدیریت می‌شود.

## آزمون‌ها

```bash
npm run test:core
```

این دستور آزمون‌های headless مربوط به Player، World، RPG، Combat، Persistence و یک آزمون اتصال بین‌ماژولی را اجرا می‌کند. آزمون مرورگر واقعی، تست روی دستگاه Android و بررسی عملکرد لمسی باید پس از نصب وابستگی‌ها و اجرای build انجام شوند.

## وضعیت هنری و صدا

تمام گرافیک بازی از صفر به سبک پیکسل‌آرت بازسازی شده و در `src/art/` قرار دارد (فقط Canvas2D، بدون وابستگی به Phaser):

- `px.ts` — جعبه‌ابزار پیکسل (دیترینگ، نورپردازی لبه، دورخط انتخابی)
- `aren.ts` — آرن (همهٔ ۱۶ انیمیشن؛ پوزها بدون تغییر)
- `enemies.ts` — ۲۴ دشمن و باس + پرتابه
- `world.ts` — کاشی‌های پلتفرم (دقیقاً هم‌اندازهٔ collider)، آسمان و سه لایهٔ پارالکس هر منطقه، NPCها، پراپ‌ها، کریستال جمع‌آوری و درخشش

برای دیدن خروجی هنر در Chrome: `node tools/art-preview/run.mjs <aren|enemies|world|selftest> out.png`.

صدا: افکت‌های کوتاه (ضربه، ضربهٔ بحرانی، شمشیر، جاخالی، جادو، فاز باس، کلیک، سکه) در `public/audio/` با `python3 tools/audio/gen_sfx.py` تولید می‌شوند و در `GameScene` به Persistence/Audio وصل‌اند. موسیقی همچنان نوار ambient پردازشی است؛ موسیقی نهایی هنوز وجود ندارد.

## محدودیت‌های نسخهٔ یکپارچه

رابط کاربری به‌صورت پیش‌فرض فارسی و راست‌چین است و امکان تغییر به انگلیسی دارد؛ متن اصلی دیالوگ‌ها و بعضی اعلان‌های داستانی هنوز انگلیسی است. گرافیک جدید پیکسل‌آرت هنوز در مرورگر و روی گوشی واقعی با Phaser اجرا و تست نشده است (محیط توسعه Phaser نداشت)؛ موسیقی نهایی هم هنوز ساخته نشده است. وضعیت دقیق تست و موارد تأییدنشده در `INTEGRATION_REPORT.md` آمده است.
